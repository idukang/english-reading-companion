# 英语陪读 · English Reading Companion

一个**全龄段、零花费、零广告、零埋点、断网可用**的英语陪读 Android 应用。

书库、词库、情景对话全部打包在安装包里，不需要注册、不需要账号、不需要 Google 服务，也不联网就能读、能点读、能查词、能跟读、能对话。

- 📦 安装包：到 [Releases](https://github.com/idukang/english-reading-companion/releases) 下载 `EnglishReadingCompanion-v1.3.0.apk`
- 🛠 由 GitHub Actions 自动编译（Gradle + Android SDK 34），每次推送到 `main` 都会重新出包
- 📱 适用：Android 7.0（API 24）及以上，华为 / 小米 / OPPO / vivo / 荣耀 / 三星等均可安装

---

## 一、为什么做这个

给家里人和自己用的英语陪读工具，要求很简单：

1. **不花钱**：没有内购、没有会员、没有“免费试用 3 天”。
2. **不偷数据**：没有统计 SDK、没有广告 SDK、不读取通讯录和短信。
3. **能离线**：通勤、地铁、飞机上都能用，流量为零。
4. **面向中国学习者**：界面、讲解、点评、错误提示全是简体中文；词库是英汉的，不是英英的。

所以整个 App 是「Kotlin 外壳 + 本地网页界面 + 系统自带能力」的组合：朗读用手机自带的 TTS，录音用系统录音接口，一个第三方依赖都没有。

## 二、功能一览

### 1. 分级书库（9 篇 + 自定义导入）

| 级别 | 适合 | 内容 |
| --- | --- | --- |
| 🧸 少儿启蒙 | 3–8 岁 / 零基础 | 日常生活、食物点单、动物朋友；短句、重复多、自然拼读友好 |
| 🎒 校园进阶 | 中小学 / 四六级预备 | 科普短文、校园故事、议论文；标出考试高频短语，配语法讲解 |
| 📰 成人实用 | 职场 / 出行 / 精读 | 入职第一天、机场通关、酒店入住；逐句拆主谓宾，讲地道表达 |

每篇都有：中文标题、难度与时长、学习目标、逐句中英对照、重点短语高亮、选择性语法讲解。

**✍️ 自定义导入**：把任意英文文章粘进来，自动按句切分（会避开 Mr. / e.g. / 3.5 这类缩写和小数），可选粘中文翻译，立刻变成可点读的文章。

### 2. 点读与复读

- 点任意一句 → 系统 TTS 朗读这一句，句子高亮并自动滚动到屏幕中间
- **朗读全篇**：逐句连读，读到哪里高亮到哪里
- 语速 0.6x / 0.75x / 0.9x / 1.0x / 1.2x / 1.4x 六档
- 口音：美音 `en-US` / 英音 `en-GB`
- **单句循环**：一句话反复听，跟读到顺为止

### 3. 点词查词 + 生词本

- 句子里的**每个单词**都可以点
- 弹出卡片显示：单词、音标、词性、中文释义、例句和例句翻译、发音按钮
- **内置离线英汉词库**：覆盖书库全部单词 + 高频核心词共 400 余条，并带词形还原（`spotted → spot`、`stories → story`、`studying → study`、`went → go`、`bigger → big`、`teeth → tooth`）
- 查不到时才有「联网查词」按钮（可选，点一下才会把这个词发给免费词典服务），不点就完全离线
- **生词本**：一键收藏，卡片复习模式（翻面看释义、朗读、标记已掌握），数据只存在本机
- **轻量间隔重复**：每个词记录复习次数与下次到期时间；「再记一下」半小时后再来，「记住了」按 1 / 3 / 7 / 15 / 30 天逐步拉长，到期的词自动排到复习队列最前面

### 4. 💬 对话互动（面对面陪练舞台）

不想只“读”，还想“说”，所以做了完整的对话练习，而且尽量做成**像真人在你面前说话**的样子。

**🎭 三个分人群的动画陪练角色**（全部是内联 SVG，不加载任何图片或视频）

| 角色 | 人群 | 说话节奏 | 性格 |
| --- | --- | --- | --- |
| 🧸 **Buddy** | 少儿启蒙 | 0.75x 慢速 | 会眨眼、说话时嘴巴动、答对弹跳撒星星，一直夸你 |
| 🎒 **Emma** | 校园进阶 | 0.95x | 点头、歪头思考，帮你把句子改成更地道的说法 |
| 📰 **Alex** | 成人实用 | 1.0x | 平稳呼吸环、倾听时专注前倾，像真实面试/会议那样追问 |

**舞台上的实时状态**
- 顶部舞台常驻：头像 + 状态牌（`正在说话…` / `正在倾听你…` / `思考中…` / `太棒了！`）+ 随声音起伏的波形环
- 说话时嘴型跟着动、眼睛会眨；答得好会弹跳并撒星星；答偏了会歪头想一想
- 三个角色可以直接在舞台上切换，下面的情景列表跟着换

**🎧 连续对话（自动接话）**
- 打开后：对方说完自动进入“倾听”状态并打开麦克风，你直接说英文就行；说完自动接下一句
- 不需要自动接话时，仍然可以手动点 🎙️ 或打字
- 答得不够好时，角色会先把你该说的那句英文念一遍，再继续对话——听得到正确版本

**📞 耳机后台连麦（像打电话一样聊）**
- 一键开启前台服务，**熄屏、切到别的应用都能继续说**；通知栏常驻一条“耳机语音对话中”，点「结束对话」随时停
- **随时打断**：AI 说话时你也开麦听着（`VOICE_COMMUNICATION` + 系统回声消除），你一张口就把它的声音停掉，它顺着你新说的内容接话，不会重复被打断的那半句
- **中英都懂**：说英文练口语；用中文问「什么意思」「怎么用英语说」「再说一遍」「慢一点」也听得懂，会用中文解释 + 英文示范，然后把你带回英语对话
- 语音识别模式一键可切：对话页底部工具栏的「🌐 中英自动」按钮循环切换 中英自动 / 🇨🇳 中文 / 🇺🇸 英文，输入框下的提示行同时写明当前模式；中英两套模型在启动时一起载入，切到中文就 100% 走中文识别器

**9 个离线情景对话**，每个 4 轮真实对话：

| 级别 | 情景 |
| --- | --- |
| 🧸 少儿 | 初次见面 · 点一份冰淇淋 · 动物朋友 |
| 🎒 校园 | 街上问路 · 图书馆借书 · 周末计划 |
| 📰 成人 | 咖啡店点单与闲聊 · 酒店入住 · 面试与自我介绍 |

对方先用英文说一句（自动朗读），你用**语音**或**键盘**回一句：

- 🎙️ **语音回答**：内置 **Vosk 离线语音识别**（英文 + 中文，不联网、不依赖系统语音服务），识别到的内容直接填进输入框；老机型或没打包模型时会自动退回系统语音
- 🛟 **说不出来也不会卡住**：识别不可用时会自动出现一条备用栏——「🎙️ 录音口语对比」+「✅ 我已说完，继续」+ 2–3 个可点就发的示范句，也能直接打字或用输入法的语音键
- 💡 **提示**：给中文提示 + 两三句可以直接点用的示范说法
- 回完立刻有**中文点评**：答得好会夸哪里好，答得偏会给出更地道的说法（可点朗读）
- 全程有中文对照开关

**读后两问**：每篇文章底部有 2 道理解题，可以用英文答、中文答，也可以点 🎙️ 说；判分只认关键信息，答对了鼓励，答偏了直接给参考答案并朗读。

### 5. 🤖 AI 自由外教（可选，填自己的免费额度）

想不限话题地聊，可以填入**你自己的** OpenAI 兼容接口：

| 服务商 | 接口地址 | 默认模型 |
| --- | --- | --- |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4/chat/completions` | `glm-4-flash`（有免费额度） |
| DeepSeek | `https://api.deepseek.com/chat/completions` | `deepseek-chat` |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions` | `qwen-turbo` |
| 硅基流动 | `https://api.siliconflow.cn/v1/chat/completions` | `Qwen/Qwen2.5-7B-Instruct` |
| 自定义 | 任意 OpenAI 兼容地址 | 自己填 |

- 接口地址、模型名、API Key 全部只保存在**本机**（应用私有存储），只发送到你填写的那个地址，中途不经任何第三方转发
- 回复自动朗读；有明显语法或用词问题时，会用一行中文 `TIP:` 指出来
- **柔和纠错「💡 Try saying」**：表达没错但可以更地道时，回复末尾会附一行更自然的英文，显示在气泡下方；这一行不会被朗读，聊天节奏不被打断
- **「🎙️ 问外教这篇」**：阅读器里一键带着文章标题、正文开头和当前选中句进入对话，可以问意思、让外教考单词、聊文章内容；没配接口时用内置离线模板，同样能答疑/考词/总结
- 开聊时会自动挑最多 3 个到期或没掌握的生词放进上下文，让外教在对话里自然带出来复现；气泡里点任意单词都能弹出释义
- **不填也完全不影响使用**：9 个离线情景 + 读后问答照样能用

### 6. 👨‍👩‍👧 多人本地学习档案

- 一个人一个档案：已读篇目、生词本、连续打卡天数、默认年龄段与语速各自独立
- 首页和设置里都能切换、新建、改名（比如「🧸 妹妹」「🎒 哥哥」「📰 我自己」），头像可选
- 全部只存在本机，不联网、不需要账号；从旧版覆盖升级时，原来的学习记录会自动归到「默认档案」，一条都不会丢

### 7. 阅读舒适度

- 字号三档：标准 / 大字 / 启蒙巨字
- 主题三档：日间 / 护眼 / 夜间（状态栏颜色跟着变）
- 中文对照一键开关、句子讲解一键开关
- 深色模式下自动适配文字对比度

## 三、安装方法

1. 打开 [Releases](https://github.com/idukang/english-reading-companion/releases)，下载 `EnglishReadingCompanion-v1.3.0.apk`
2. 在手机上点开安装；系统提示“未知来源”时，允许浏览器或文件管理器安装应用即可
3. 首次使用跟读或语音回答时，会申请**麦克风权限**——只用于录音和语音识别，拒绝也不影响阅读和查词

> 安装包用项目自己的 Release 密钥签名，可以直接安装；如果以前装过 debug 签名或别的签名的版本，先卸载旧版再装。

### 没有 Google 服务的手机（华为 / 荣耀等）

- **朗读**：用的是手机自带的 TTS 引擎（华为、小米、OPPO 等系统都自带），不依赖 Google。若系统里没有中文/英文语音包，到「系统设置 → 无障碍 → 文字转语音」里选一个引擎并下载英语语音即可。
- **语音识别**：优先用内嵌识别服务；失败时自动改走系统语音输入面板（手机自带或输入法提供的那个）。两条都不行时，对话页会出现备用栏，然后你可以：
  - 直接用键盘输入英文（推荐，最稳）；
  - 用输入法自带的语音键说话（讯飞、搜狗、百度输入法都支持）；
  - 用「跟读录音 + 回放对比」练发音，这条路径只需要麦克风，任何机型都能用。
- **联网功能**：不联网也能用全部核心功能；「联网查词」在国内网络下可能连不上，所以离线词库才是主路径。

## 四、自己编译

### 用 GitHub Actions（推荐，不用本地环境）

推送到 `main` 即自动编译并发布：`.github/workflows/build-apk.yml` 只有一行 `bash scripts/ci-build.sh`，
真正的构建逻辑在 [`scripts/ci-build.sh`](scripts/ci-build.sh) 里——它会在 runner 上准备好 JDK 17、Android SDK 34、
Gradle 8.7，检测到签名 Secrets 时编译 `assembleRelease`（否则回退 `assembleDebug`），生成 `SHA256SUMS.txt`，然后把 APK 传到 Release `v1.3.0`。
好处是改构建流程不用动 workflow 文件。也可以到 Actions 页面点 **Run workflow** 手动触发。

### 本地编译

需要 JDK 17 + Android SDK 34：

```bash
# 在项目根目录
gradle :app:assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

（仓库里带的是 `gradle-wrapper.properties`；如果你本机有 Gradle 8.7，也可以先 `gradle wrapper` 生成 `gradlew` 再 `./gradlew assembleDebug`。）

## 五、目录结构

```
app/src/main/
├── AndroidManifest.xml          # 只申请 INTERNET + RECORD_AUDIO
├── java/com/idukang/readingcompanion/
│   ├── MainActivity.kt          # WebView 外壳 + 中英分段 TTS + 录音 + 语音识别桥 + HTTPS 请求桥
│   ├── VoskEngine.kt            # 离线语音识别（16kHz AudioRecord + AEC + 打断 + 中英双模型）
│   └── VoiceCompanionService.kt # 耳机后台连麦的前台服务（唤醒锁 / 音频焦点 / 常驻通知）
├── res/                         # 主题、颜色、图标
└── assets/www/                  # 全部界面与内容（离线）
    ├── index.html               # 页面骨架
    ├── style.css                # 三套主题 + 字号体系
    ├── app.js                   # 交互逻辑（点读/查词/生词本/对话/AI）
    ├── library.js               # 分级书库 9 篇 + 讲解 + 读后问答
    ├── dict.js                  # 离线英汉词库 + 词形还原
    ├── persona.js               # 三个动画陪练角色（内联 SVG）+ 舞台状态机
    └── scenarios.js             # 9 个离线情景对话
```

技术栈：Android `Activity` + `WebView` + `JavascriptInterface`，界面用原生 HTML/CSS/JS，连 AndroidX 都没有。
唯一的第三方依赖是离线语音识别 **Vosk**（`com.alphacephei:vosk-android` + JNA，Apache-2.0，本地推理、不联网），
语音模型（英文 small-en-us-0.15 / 中文 small-cn-0.22，各约 40MB）在构建时下载并打进 `assets/`，所以安装包约 90MB。
没有任何统计、广告、崩溃上报 SDK。

## 六、隐私说明

- 不收集任何个人信息，不含统计、广告、崩溃上报 SDK，不读取通讯录、短信、相册、位置
- 权限都很克制：
  - `INTERNET`：仅用于你主动触发的「联网查词」和你自己配置的 AI 接口
  - `RECORD_AUDIO`：跟读录音、语音回答、离线识别；**语音只在本机用 Vosk 转成文字，音频不上传、不保存**
  - `FOREGROUND_SERVICE(_MICROPHONE/_MEDIA_PLAYBACK)` + `WAKE_LOCK`：只在你打开「耳机后台连麦」时使用，熄屏后继续听你说的
  - `POST_NOTIFICATIONS`：显示那条「耳机语音对话中」的通知（Android 13+）；不给也能用，只是看不到通知
- 生词本、已读进度、设置、AI 配置都存在本机应用私有存储里，卸载即清除
- 应用内所有跳转都被拦截，不能打开外部网页

## 七、常见问题

**Q：点了句子没声音？**
A：先确认手机有可用的 TTS 引擎和英语语音包（设置 → 无障碍 → 文字转语音）。部分机型默认引擎是“Google 文字转语音”，没装 Google 服务时为空，换成本机自带的引擎即可。

**Q：语音回答按钮点了没反应？**
A：v1.1.0 起默认用打包在安装包里的 Vosk 离线识别，不再依赖系统的语音服务，国内 ROM 上也能用。第一次点会花 1–2 秒把模型解包到应用私有目录。如果仍然没反应，对话页会自动出现备用栏（录音对比 / 我已说完，继续 / 示范句），也可以直接打字。

**Q：耳机连麦熄屏后还有效吗？**
A：有效。它用前台服务 + 部分唤醒锁保持麦克风和朗读，通知栏会一直显示「耳机语音对话中」，点「结束对话」或通知上的叉才会停。注意：按住手机把 App 从最近任务里划掉，对话会结束（这时网页层已经被系统清掉了）。

**Q：蓝牙耳机能用吗？**
A：朗读会走蓝牙耳机（A2DP）没问题。说话时，有线耳机会用耳机上的麦克风；蓝牙耳机通常只接管“听”，麦克风还是手机的——离手机近一点说就行。

**Q：能改内容吗？**
A：可以，`assets/www/library.js`、`dict.js`、`scenarios.js` 就是纯数据文件，按同样的格式加文章、加单词、加情景即可。

**Q：会不会有一天开始收费或者加广告？**
A：代码是公开的，谁都可以核对；就算这里变了，你也可以自己编译之前那份。
